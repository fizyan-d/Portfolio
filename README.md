# Interactive Portfolio Core // Fiziyan

An interactive, high-contrast developer portfolio engineering matrix bridging full-stack web applications and physical IoT hardware systems. Designed with a performance-first cyber-industrial neo-brutalist aesthetic, featuring a responsive bento-grid layout, fluid custom interactive cursor tracing, and synchronous hardware-software schemas.

**Live Production Link:** [portfolio-lovat-delta-20.vercel.app](https://portfolio-lovat-delta-20.vercel.app/)

## 🛠️ Tech Stack & Engineering Core

- **Frontend Core:** Next.js (App Router), React, TypeScript
- **Styling & Motion:** Tailwind CSS, Framer Motion
- **Animations & Icons:** Iconify, Embedded SVG Engineering
- **Deployment Layer:** Vercel Performance Edge Network

## 🪟 Architecture & Features

### 1. Hyper-Speed Loading Frame
- Implements a hardware-inspired microcharacter structural spinner state with synchronous vector motion translation.
- Includes automated environment configuration suppressors to mitigate layout shifts and browser-extension attribute hydration mismatches.

### 2. Custom Morphing Cursor Tracking
- A hardware-reactive magnetic custom cursor matrix that dynamically senses interactive viewport targets.
- Transitions automatically between system tracking dots and textual hover indicators (`[LIVE]`, `[CODE]`, `[PRODUCTION]`).

### 3. Tactile Bento-Grid Configuration
- A mathematically aligned bento structural array mapping engine projects across isolated micro-containers.
- Full responsive support with deep touch-target configurations optimized for seamless mobile-first workflows.

## 🚀 Local Deployment Setup

To execute the portfolio layout matrix on a local workstation environment, ensure you have Node.js installed via a version manager (`fnm` or `nvm`), then configure:

```bash
# Clone the architecture repository
git clone [https://github.com/fizyan-d/portfolio.git](https://github.com/fizyan-d/portfolio.git)

# Navigate into the project folder root
cd portfolio

# Install localized package dependencies
npm install

# Initialize local engine environment
npm run dev
